Github repo for PINN project in CEE 292

This project explores the possibility of using PINNs as a surrogate forward model for a coupled thermo-elastic
problem. 

Two PINN architectures, strong form (SF) PINNs and Deep Energy Method (DEM) PINNs, have been implemented in
`thermoElastic_PINN.ipynb`. The FEM output is treated as the ground truth and is shared in `thermal_input_out_mech0.e`,
which is generated by the MOOSE input file `thermal_input.i`. Since we solve a coupled problem, `mechanical_subApp.i` 
**must** be in the same directory as the thermal input file.
